# بيانات أكواد تطبيق «دليل الأكواد»

مستودع البيانات اللي التطبيق بيقرأ منه الأكواد. **مفيش كود برمجي هنا — ملفات JSON بس.**

## الملفات

| الملف | إيه هو |
|---|---|
| `version.json` | رقم الإصدار الحالي. التطبيق بيجيبه الأول (٤٠ بايت) — لو اتغيّر بس بينزّل الأكواد |
| `codes.json` | الأكواد كلها |

## إزاي أحدّث الأكواد؟

**من المتصفح مباشرة (الأسهل — من الموبايل كمان):**

1. افتح `codes.json` هنا على GitHub
2. دوس على أيقونة القلم ✏️
3. عدّل الكود
4. افتح `version.json` وزوّد الرقم بواحد
5. Commit

**التحديث بيوصل لكل المستخدمين خلال دقايق — من غير تحديث من متجر Play.**

> مهم: لازم تزوّد الرقم في `version.json`، وإلا التطبيقات مش هتعرف إن فيه جديد.

**أو بأداة المحرّر:** افتح `tools/editor.html` من مشروع التطبيق — بتعدّل في جدول
وبتزوّد الإصدار لوحدها وبتنزّلك الملفين جاهزين للرفع.

## الرابط اللي التطبيق بيقرأ منه

```
https://cdn.jsdelivr.net/gh/<الحساب>/<المستودع>@main/version.json
https://cdn.jsdelivr.net/gh/<الحساب>/<المستودع>@main/codes.json
```

jsDelivr شبكة توصيل مجانية بتعمل كاش للملفات، فالتحديث ممكن ياخد دقايق يظهر.
لو عايزه فورًا:

```
https://purge.jsdelivr.net/gh/<الحساب>/<المستودع>@main/codes.json
```

⚠️ **المستودع لازم يكون Public** عشان jsDelivr يقدر يوصله.
